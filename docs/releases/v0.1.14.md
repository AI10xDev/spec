# Spec v0.1.14: Agent Memory

Source release adding agent memory since v0.1.13. The implementation is committed
at `924e7e6`; the release commit updates documentation only. No prebuilt binaries
are attached. Release identity follows Git tags; package manifests remain `0.1.0`.

## Highlights

- Each backend-managed initial build, queued build, and continuation is a separate
  memory sweep with its existing job UUID, session/parent links, spec revision,
  remote identity, and backend-observed timestamps.
- Four structured agent-report properties: **what changed**, **why**,
  **what was checked**, and **what remains unresolved**.
- Authenticated, read-only GraphQL at `POST /api/memory/graphql`, backed by bundled
  SQLite. Query individual sweeps or bounded history by job, session, parent,
  spec, remote configuration, status, and time.
- Checkpoint and terminal-log capture preserve valid reports in durable JSON,
  surviving restart, output truncation, and database reconstruction.
- Background indexing and incremental legacy-job import do not block builds or
  cancellation when SQLite is busy or unavailable. Unknown historical metadata
  and missing, invalid, or truncated reports stay explicit.

Agent reports are **unverified claims**, never proof that checks passed or work is
complete. Operational run status remains independent. A successful process exit
does not manufacture a successful report.

Full changes: https://github.com/AI10xDev/spec/compare/v0.1.13...v0.1.14

## Install Or Upgrade

```sh
git clone --branch v0.1.14 https://github.com/AI10xDev/spec.git
cd spec
./setup.sh
```

The guided wizard needs Linux and Python 3.9+. Manual `./run.sh --local` remains
available. Rust/Cargo and Bun (or Node/npm) are needed to build the app. No new
database service, provider key, or environment variable is required for memory.

For existing installations, preserve uncommitted changes, specs, and private
settings before selecting the tag. Back up the **entire `.spec-output/`
directory**, including JSON records and `memory.sqlite3`. Rebuild and restart the
local Rust backend with the same workspace and settings, then reconnect using
its new token URL. Publication does not restart services or update remote engines.
Already-running remote invocations do not receive the new report instructions.

See [Installation](https://github.com/AI10xDev/spec/blob/v0.1.14/docs/INSTALLATION.md)
and [Build memory](https://github.com/AI10xDev/spec/blob/v0.1.14/docs/BUILD_MEMORY.md)
for query examples, time semantics, storage limits, and recovery behavior.

## Scope And Limits

Memory covers builds launched by this web backend, not individual model turns,
arbitrary standalone CLI jobs, or every remote `.out` file. Repository saves,
optimizers, and Performance runs are excluded. Existing local JSON jobs are
imported without rerunning work or guessing absent timestamps/session IDs.

GraphQL history is not automatically sent back to remote agents. Callers can
retrieve relevant prior memory and reconcile it against code/tests before using
it as context; existing prior-output review instructions remain active.

configured cloud services can incur costs.

does not remove tracked history from Git clones or constitute a historical secret
audit. Unrelated local changes and private settings are not included in archives.

# Spec v0.1.13

Source release covering changes since v0.1.12, including the Azure Realtime
rollback at `48844ba` and updated release documentation. No prebuilt binaries are
attached. Release identity follows Git tags; package manifests remain `0.1.0`.

## Highlights

- Persistent saved-editor build queues: save a fixed snapshot during an active
  build for execution after confirmed successful completion. Queue state survives
  browser/server restarts; later autosaves do not alter queued instructions.
- Opt-in Computeruse bridge: synchronize a shared instruction file, import remote
  edits with conflict checks, and run/stop the separately configured Computeruse
  process without silently falling back to a normal build.
- Conversational guided setup with free-text requirements, dependency checks,
  optional SSH/AI configuration, hidden key input, private saved launch settings,
  and separate confirmation before saving or starting.
- Azure Realtime WebRTC voice with near-field noise reduction and spoken
  interruptions. The intermediate Whisper/audio-mini recording implementation was
  reverted; it is not the voice path shipped in this release.
- Everyday-development README, direct support link, and updated installation and
  upgrade instructions for the tagged release.

Full changes: https://github.com/AI10xDev/spec/compare/v0.1.12...v0.1.13

## Install Or Upgrade

```sh
git clone --branch v0.1.13 https://github.com/AI10xDev/spec.git
cd spec
./setup.sh
```

The wizard needs Linux and Python 3.9+. The manual `./run.sh --local` path remains
available without Python or AI credentials. Rust/Cargo and Bun (or Node/npm) are
needed to build the app. See
[Installation](https://github.com/AI10xDev/spec/blob/v0.1.13/docs/INSTALLATION.md)
and the
[Computeruse guide](https://github.com/AI10xDev/spec/blob/v0.1.13/docs/COMPUTERUSE.md).

For an existing installation, preserve your workspace, private settings, and
uncommitted changes before selecting the tag. Rebuild and restart the actual
local Rust backend, then reconnect with its new token URL. Publication does not
restart services or update remote engines, model runtimes, or existing supervisors.

If you used the intermediate Whisper/audio-mini version, reconfigure the server
with `AZURE_OPENAI_REALTIME_ENDPOINT`, `AZURE_OPENAI_REALTIME_API_KEY`, and
`AZURE_OPENAI_REALTIME_DEPLOYMENT`. A private voice-only file is selected through
`SPEC_AZURE_REALTIME_ENV_FILE`. Keep text-chat settings unchanged. Old wizard
setups are not rewritten, and cloud deployments are not deleted. See
[Azure voice setup](https://github.com/AI10xDev/spec/blob/v0.1.13/docs/realtime.md#azure-setup).

A separate live Azure Realtime smoke check used the restored UI, real WebRTC,
and a fake browser microphone. It verified successful negotiation, a spoken
answer to a synthetic text question, incoming audio packets, and microphone
release on Stop. This does not validate physical microphone transcription,
noisy-room performance, or audible playback on a user's speakers.

Live SSH/desktop control, GPU workloads, non-Chromium browsers, macOS, and the npm
fallback were not validated for this release. Computeruse and coding engines are
external integrations, not bundled runtimes. Tool execution is trusted and
unsandboxed; configured cloud services can incur costs.

Source archives exclude historical `.out` logs and `.spec-runs` artifacts.
Those exclusions do not remove tracked history from Git clones and are not a
historical secret audit. Existing local changes and private settings are not
included in the release archives.

# Spec v0.1.15: Memory Retrieval And Private Backups

Source release of the completed memory and Azure storage work since v0.1.14,
including installation and everyday-use documentation. No prebuilt binaries are
attached. Release identity follows Git tags; package manifests remain `0.1.0`.

## Highlights

- Find relevant previous build work through GraphQL `memoryContext`: filter by
  job keys and timestamps, rank by keywords, and retrieve a bounded chronological
  context with source citations. Missing reports and unverified claims remain
  explicit. Retrieval is caller-driven, not automatically added to build prompts.
- Back up saved specs from **Settings > Azure Blob Storage**. Save your storage
  account name, existing private container, and account access key, then choose
  **Upload all specs** and confirm. Credentials stay server-side and separate
  from AI settings. Saving settings alone does not upload files.
- Uploads reject public containers and stale destinations. If another tab changes
  the account/container, reopen Settings and confirm the new destination before
  retrying. Requests cannot silently upload to a different destination from the
  one confirmed.
- AI settings now explain which saved provider/model new spec builds use and
  clarify that resetting settings may restore Azure defaults on the execution
  host. Save a different provider to keep builds off Azure.

Full changes: https://github.com/AI10xDev/spec/compare/v0.1.14...v0.1.15

## Install Or Upgrade

For a new installation:

```sh
git clone --branch v0.1.15 https://github.com/AI10xDev/spec.git
cd spec
./setup.sh
```

The guided wizard requires Linux and Python 3.9+. Building requires Rust/Cargo
and Bun (or Node/npm); see the installation guide for tested versions. To start
with just the editor, use `./run.sh --local`. Basic editing needs no provider
account, SSH host, GPU, or Azure storage account. Remote builds and cloud backups
are optional and can incur provider costs.

For an existing installation, preserve uncommitted work before selecting the
tag. Back up saved specs, the entire `.spec-output/` directory (including JSON
records and `memory.sqlite3`), and private settings. Storage settings, when
configured, live in a private sibling `<SPEC_SETTINGS_FILE filename>.storage.json`
file. Rebuild and restart the local backend with the same workspace/settings,
then reconnect using its new token URL. Publication does not restart services,
upgrade remote engines, or change already-running remote invocations.

## Scope And Limits

Backups include saved, top-level UTF-8 workspace documents up to 2 MiB each,
including extensionless specs. Unsaved buffers, `.out` logs, `Agent.md`, hidden
files, directories, symlinks, and unsupported files are excluded. Uploads overwrite
matching blob names but do not delete local files or unrelated blobs. Check the
uploaded/skipped/failed counts. A failed batch may already have uploaded files;
retrying is not transactional. There is no automatic sync or restore UI.

Only Azure public-cloud endpoints and account access keys are supported. Create
the private container yourself; the app does not change Azure permissions. It
checks privacy before the batch and each upload, but later administrator changes
are outside its control. Keep anonymous access disabled and prefer a dedicated
account/container because account keys grant broad access.

Memory retrieval searches at most 500 filtered candidates and returns at most
20 entries within its context byte budget. Keyword matching is lexical, not
semantic. Consult truncation/omission indicators and surrounding history before
treating a selected timeline as complete. Agent reports remain untrusted evidence.

external coding engines, production SSH, physical microphones, GPU workloads,
non-Chromium browsers, macOS, and the npm fallback were not validated. No running
services were restarted by publication.

Source archives exclude historical `.out` and `.spec-runs` artifacts; Git clones
still contain tracked history. This is not a historical secret audit. Unrelated
local feedback-editor changes, logs, and private settings are not in this release.
